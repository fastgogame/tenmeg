# Tenmeg
https://tenmeg.vercel.app/
Сжатие видео до 10 МБ - максимальный размер для загрузки в Discord.

Работает прямо в браузере через ffmpeg.wasm (FFmpeg, собранный в WebAssembly).  H.264 + AAC.
React, TypeScript, Vite, Tailwind CSS, ffmpeg.wasm. Хостинг: Vercel.

- Битрейт рассчитывается от длительности видео, чтобы файл поместился в ~9,5 МБ: `битрейт = (размер × 8) / длительность − битрейт звука`.
- Чем меньше битрейт, тем меньше разрешение.
- Если файл всё равно вышел больше 10 МБ, пробует второй раз с меньшим битрейтом.
- Максимальный размер исходного файла: 200 МБ.
- Если видео слишком длинное (больше ~3,5 минут), в 10 МБ оно не влезет без сильной потери качества.
